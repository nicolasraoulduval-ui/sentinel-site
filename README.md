# Sentinel

Portfolio monitoring pour fonds VC et PE.

Démo en ligne : https://sentinelfund.fr/

## Ce que fait Sentinel

- Collecte automatique des KPIs auprès des participations (ARR, MRR, burn, runway, headcount)
- Dashboard portefeuille consolidé en temps réel
- Alertes sur variations critiques (cash runway < 6 mois, churn, etc.)
- Génération de reportings LPs (SFDR Article 8/9, PAI) en quelques clics
- Vue cap table et waterfall de liquidation par participation

## Stack

Prototype single-page HTML/CSS/JS. Pas de backend pour la démo publique.
